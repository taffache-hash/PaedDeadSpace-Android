# Changelog

All notable changes to PaedDeadSpace Android will be documented in this file.

## [Unreleased]

No user-visible changes yet.

## [1.0.1] - 2026-09-19

### Changed

- Technical release patch created after Zenodo GitHub preservation was enabled.
- Android application version advanced to `1.0.1` (`versionCode` 2); PaedDeadSpace-Core remains frozen at `1.0.0` with no scientific or intended-use changes.

## [1.0.0] - 2026-09-19

### Added

- Native Android workflow for educational and research use by healthcare professionals.
- Fully offline invocation of the byte-verified PaedDeadSpace-Core v1.0.0 package.
- Explicit scenario entry with no hidden weight, age, age-unit, tidal-volume, respiratory-rate, or patient-model defaults.
- Core warnings, mathematical model-boundary handling, ordered numerical results, and provenance details.
- In-memory-only state, no accounts, analytics, telemetry, network access, storage, sharing, or export.
- Automated Core-integrity, bridge-equivalence, Kotlin unit, Compose UI, lint, and release-build checks.

### Distribution boundary

This source release and its unsigned bundle precede the Zenodo archive, manuscript update, Play signing, policy declarations, internal testing, and any production distribution.
